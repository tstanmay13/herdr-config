# Lessons

## 2026-11-05: progress in the orchestrate workflow outlives sessions
Implementers are usually one-off sessions (one unit, then gone), so anything that accrues per
session (levels, stats) never grows. Attach lasting progress to something that survives the
session (a Pokémon line, the run, the human), and credit work by the session name state.md
records, not by which terminals are open now.
